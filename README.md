# ADHD Accountability Partner Bot 🤖

A lightweight serverless bot deployed on Vercel that pings your Telegram daily with a fresh, friendly, low-friction accountability prompt generated by Google Gemini.

## Local Development & Testing

1. **Get your API Keys:**
   - Text `@BotFather` on Telegram to create a free bot and get a **Telegram Bot Token**.
   - Text `@userinfobot` on Telegram to discover your personal **Telegram Chat ID**.
   - Grab a free API key from [Google AI Studio](https://aistudio.google.com/).

2. **Setup Environment:**
   - Copy `.env.example` to `.env` and fill in your values.
   - Run `npm install -g vercel` if you haven't installed Vercel CLI.
   - Run `npm run vercel:dev` in the root folder to start your local Vercel dev server on port `9120`.
   - Trigger the check-in endpoint manually in your browser or with cURL: `http://localhost:9120/api/cron-checkin`
   - To sync local env vars to Vercel for one target environment, run `./scripts/push-vercel-env.sh production .env`.
   - To trigger the deployed cron endpoint with your local `CRON_SECRET`, run `./scripts/trigger-vercel-cron.sh <deployment-url> .env`. The script uses `vercel curl`, so it works against protected deployments too.

## Deploy to Vercel

1. Push this project to GitHub.
2. Link your repository to a new project in your **Vercel Dashboard**.
3. Add your Environment Variables in your Vercel Project Settings:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `GEMINI_API_KEY`
   - Optional for an initial Telegram smoke test: `INITIAL_TELEGRAM_MESSAGE=Sup, chief, I'm here to help you.`
4. Deploy! Vercel will automatically detect the `vercel.json` file and register the scheduled Cron Job.

If you set `INITIAL_TELEGRAM_MESSAGE`, the deployed function will send that exact text instead of calling Gemini. Remove the variable after the first successful delivery so later runs go back to generated check-ins.
